# MagicBayLTE 1.4.3

- 配置文件丢失时保持 LTE 停用；正常升级保留明确保存的启用选择。
- 卸载将 LTE 重置为停用并清理运行状态，重装默认停用；可添加 `--remove-logs` 删除日志。
- 日志与运行状态仅管理员和当前控制台用户可读，普通用户不能修改后台文件。
- “…”菜单新增“关于与开源许可证”，可离线查看许可证与第三方声明。
- README 补充联网健康检查及本地诊断数据说明。

更新会暂停旧后台服务。请先连接可用的 Wi-Fi 或有线网络，并退出旧版界面后安装。安装包未经过 Apple 公证。

本版离线检查和安装包解包检查不替代全新安装、升级、卸载及真实模块切网验证。
